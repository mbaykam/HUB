# HUB

此项目是基于 Minke 和 DeepSeek Harness 的独立定制分支。

最新维护的项目说明与安装步骤请参阅 [English README](README.md) 和
[Documentation](docs/README.md)。另有 [Türkçe](README.tr.md) 项目介绍。

当前版本是实验性、Windows 优先的源代码项目。语音、知识整理与 Telegram
通话需要额外的运行环境和配置；请以维护中的安装文档为准。
