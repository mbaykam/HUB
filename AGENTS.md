# HUB development

From v1.0.0 onward, focus releases on complete, polished features. Use
[RELEASING.md](RELEASING.md) as the definition of done: finish the user workflow,
verify useful feedback and recovery, and avoid publishing placeholders or claims
that go beyond the evidence.

Daily user interfaces are the PWA and Telegram. Preserve existing conversations,
Knowledge sources and account/model/character/speech settings. Label simulated
checks honestly. Deliver matching installed host and PWA versions when publishing.
