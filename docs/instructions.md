# AI instructions

Open **Settings → HUB → AI instructions** on desktop or in the PWA. The source selector
shows the shared Markdown files, each character's instructions and, when enabled,
Knowledge AI's editorial instructions. The model overview explains which sources
each assistant uses.

- **SOUL.md** contains your shared conversational behavior rules.
- **USER.md** contains background and preferences you choose to supply to your
  conversational assistants. It is independent of automatic knowledge retrieval.
- **Character instructions** belong to that character. Changing its model keeps
  its instructions; calling another character uses that character's instructions.
- **Knowledge AI** has separate editorial instructions and fixed note-processing
  rules. Its strict structured-output task does not inherit SOUL.md or USER.md.
- **AGENTS.md** shows the existing native global instruction file. DeepSeek Harness
  can also load workspace/project instruction files. This source is read-only in
  this screen; manage those files through your existing file editor.

SOUL.md and USER.md start empty. They add no behavior until you write something.
Their real paths appear in the editor; changes made in an external editor are
also read before the next model request. They are stored under the private
character configuration directory, outside the source checkout. Earlier contents
are retained privately, and a stale edit cannot overwrite a newer version.

Character and curator edits update their existing settings rather than creating
competing copies. Shared changes apply on the next reply. Restart an active voice
session after changing that character's personality, because voice sessions keep
the character configuration admitted at connection time.

If a chat is selected, **Last sent instructions** shows its actual latest system
prompt and recent native workspace instruction projections. It is an inspection
of the selected chat, not a fabricated preview for every model in the overview.
Tool and channel rules are generated by the harness; this display does not change
permissions or grant tools that a character was denied.
