# HUB 1.6.2

Knowledge AI's instructions now explicitly distinguish keeping the original
conversation read-only from saving supported annotations alongside it. Any
relationship, reflection, profile suggestion or extracted memory requires an
organization decision. Archive-only and skip decisions keep all mutation arrays
empty. The original chat remains in its separate archive in every case.

Evidence validation and saved spending limits remain unchanged. Invalid model
outputs are still rejected; records without useful new information can finish
without creating a note. Provider failures and timeouts remain visible for review.

Includes the streaming and quota recovery fixes from 1.6.1. Physical acceptance
of the earlier phone voice changes remains a separate pending check.
