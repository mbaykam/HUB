# HUB 1.3.2

The voice Background / Resume button now reaches HUB's listening controls.
The previous host omitted this endpoint from its registered routes, so the
button returned “not found” even though the listening runtime supported it.

Use Background during an open call to wait for your configured wake phrase,
or Resume to continue without saying the phrase. The same PWA control applies
to a connected Telegram call. Calls and warm speech models stay connected.

The fix preserves speech engines, voices, character instructions and existing
conversations. Automated checks cover actual plugin registration, authentication,
call ownership and runtime dispatch. Synthetic browser/audio checks do not replace
physical phone acceptance of wake recognition and background browser behavior.
