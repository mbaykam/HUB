# HUB 1.9.0

Conversation canvas now supports self-contained interactive HTML/CSS/JavaScript
alongside diagrams and Vega charts. Visuals appear inside chat, with optional
full-screen expansion, local reset and controls to follow or pause new versions.
HUB no longer adds game-specific controls to arbitrary saved HTML files.

Every conversation character receives shared canvas.md guidance explaining when
a visual is useful, how to publish and update it, and its offline isolation.
The guide is inspectable in AI Instructions; personality and tool permissions
remain unchanged. The latest successful canvas can reopen from its saved chat.

See [Interactive canvas](../interactive-canvas.md) for use and limits.
