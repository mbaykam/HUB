# HUB 1.9.2

New voice conversations appear automatically in the left Recents panel alongside
written chats. They remain accessible after the call ends and when the PWA is
reopened. There is no need to ask the character to save each conversation.

This changes the default for new conversations. Existing transcripts, individual
history choices and character/model/speech settings are preserved. Older hidden
voice conversations can still be added individually through Voice History.

Foreground voice interruption now checks a short microphone sample against the
audio sent to playback before admitting an interruption. The comparison uses
audio rather than matching recognized words, with a local 320 ms verification
window and a bounded, temporary RAM reference. Microphone capture stays open.
It adds no separate model request. Phone-speaker performance still needs an
actual device test; this is echo protection, not speaker identity recognition.

Knowledge has a compact single-row header. Counts and file import live in its
three-dot menu, while zoom and View controls sit at the bottom of the graph.
The default 2D view separates domain groups and the chat archive, displays their
names at overview scale, and exposes a return to all knowledge after focusing
a group. Notes, memberships and source links are unchanged.
