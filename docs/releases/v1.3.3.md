# HUB 1.3.3

Character names are editable labels. Conversation handoffs and background work
now use the configured role and stable character ID from the current roster,
so renaming a character keeps its model, tools and conversation bindings.

The initial voice character is Vera; the initial custom specialist is B4D,
pronounced “Bad”. Existing saved names and settings remain under the operator's
control. The initial wake phrase is Vera, and can be changed in Speech settings.

Camera, shared instructions and attachment context describe the voice assistant
by its role instead of assuming a fixed name. Original conversation history is
preserved. This update does not change recognition or speech synthesis engines.

Validation covers a real native handoff by stable ID, renaming the active
character mid-conversation and continuing with the same model, local attention
matching, uploads and global speech settings. Scripted model responses and
synthetic wake text do not establish physical recognition quality.
