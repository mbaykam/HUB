# HUB 1.10.1

The phone chat composer now keeps its menu, voice and Send controls on one compact
row. The repair uses the actual upstream input component, including its slot
wrappers, rather than a simplified layout fixture. Existing draft, attachment,
Send and Stop handlers stay intact.

Home loads the full Knowledge graph engine only when requested. Verified,
versioned UI assets are minified and can use private immutable caching; API
responses, login pages, conversations and drafts are not cached by this change.
Authorization remains required before conditional asset responses.

The separate iPhone update removes the repeated Start voice confirmation after
an explicit Speak tap. OS microphone permission and same-origin, main-frame
user-navigation checks remain. Ended conversations resume only through the
explicit Resume action. Native compilation and physical-device acceptance are
recorded separately; these changes do not claim measured phone startup latency
or a fully installed/offline UI.
