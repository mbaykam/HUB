# HUB 1.5.0 — Provider usage

Settings → HUB → Usage now includes Unlid account credits and Soniox speech
costs, request counts and audio durations alongside the existing provider cards.
Small charges keep their precision. Each card identifies its account or project
scope, and Soniox periods use UTC dates. Soniox's billing link opens its console
for remaining credit information.

Failed or missing connections show a useful message without turning missing
data into zero usage. Unlid's current balance remains visible if its lifetime
totals are temporarily unavailable. Provider keys and account identities never
enter the PWA's usage response.

Character instructions, models, speech choices and existing conversations are
preserved. This update does not change speech recognition or synthesis.

See the [usage guide](../usage.md).
