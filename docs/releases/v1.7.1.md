# HUB 1.7.1

Home gives Knowledge more space and makes daily planning easier to use.

- The larger 2D graph uses the real brain notes, domain colors and connections.
  Select a note to open its original sources; zoom and Fit are available. Compact
  statistics keep the separate chat archive visible without crowding the graph.
- Press **+** beside an empty to-do field to open the editor, or type a title and
  submit it directly. A delayed background refresh cannot hide a newly saved item.
- Home shows today's commitments with the calendar behind its date button.
  **Open planner** retains week browsing, editing, Soon/Later and recovery of
  completed or removed items. Recent replies occupy less Home space.
- Chat options sit in the bottom bar instead of covering card content. In a wide
  PWA, the secondary Panel no longer intercepts the Settings Close button.
- Tools lists current capabilities separately from retired memory integrations.
  Model requests advertise the selected character's existing allowed tools, so a
  restricted assistant can delegate a task instead of trying a disabled tool.
  Execution guards and saved tool permissions are retained.

Shared `USER.md` preferences are loaded when each new request is assembled. Main,
voice, specialist and delegated-worker paths have native integration coverage;
Knowledge curation retains its separate instruction scope. Edit your own profile
in **Settings → AI instructions → Benim hakkımda**.

This update preserves conversations, Knowledge originals, character/model/account
settings and speech selections. It does not connect email or WhatsApp accounts,
and does not change transcription, playback or microphone settings. See
[daily use and the next connection steps](../daily-assistant.md).
