# HUB 1.3.0

Long voice conversations can wait quietly until called. **Background / Resume**
controls keep an open PWA or Telegram call connected, and an adjustable idle
interval switches to Background automatically. Local recognition checks wake
phrases without asking an LLM to interpret every surrounding conversation.
An optional, bounded recent excerpt can accompany the next spoken request;
background words are not treated as personal-memory evidence.

Knowledge AI can select useful user quotations from chats and save them as
separate, source-linked brain notes. It preserves original conversations and
existing notes, uses the existing organization request/budget, supports review,
deduplication, retry without another extraction request, and separate note undo.

See [operating details and limits](../background-listening.md). Phone audio,
speaker echo and locked-screen behavior still need physical-device acceptance;
local synthetic and browser checks do not certify those conditions.
