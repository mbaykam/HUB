# HUB 1.7.0

Conversations, browser apps and background work are easier to use from the PWA.

- Open generated HTML apps from **Apps** or their file links. They fill the PWA
  screen, with a clear Close button and optional touch controls for keyboard games.
  Local apps run in an isolated frame; external network services are not enabled.
- Home reads running work and recent results from HUB when you reopen the PWA.
  Opening the app does not repeat a task. “Reply ready” means a response is available,
  rather than certifying that every requested operation succeeded.
- Successful file writes can accompany their source conversation in Knowledge.
  Originals are retained, supported text files provide excerpts to Knowledge AI,
  and saved information can link back to its conversation and original file.
- Model selection has a compact catalogue and a separate settings screen.
  OpenRouter reasoning choices follow the model’s published capabilities, including
  models that require reasoning. Automatic output uses an operating allowance of
  up to 32,768 tokens rather than reserving the model’s entire output capacity.
  Explicit larger allowances remain available within the model’s capacity and
  your provider’s actual credit limits.
- Conversation titles sit beside Home. Session export and statistics are under
  the **⋮** menu; unused feedback and branching controls are hidden in the PWA.
  Dollar prices retain readable Markdown instead of being interpreted as formulas.
- Settings opens HUB controls directly, including General and UI update controls.
  Knowledge readers have less header chrome and a visible return to All knowledge.
  Home cards scroll above the interaction bar without overlapping it.

Existing character, model, account, instruction and speech selections are preserved.
This release changes no microphone, transcription or voice model settings.
