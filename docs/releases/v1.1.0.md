# HUB 1.1.0

This update makes character memory permissions easier to understand and adds
inspection of the complete conversational request HUB dispatches to a model.
Existing conversations, Knowledge sources, characters and settings are retained.

- **Characters → Capabilities** groups memory reading, saving notes, Skills and
  other tools. Existing partial selections are preserved. The second-brain
  profile removes redundant legacy MCP memory tools without deleting their data.
- **Characters → Full prompt** shows the last actual request for that character,
  including shared instructions, conversation history, tools and model options.
  Refresh or download the full JSON. Inspection makes no model call and is read-only.
  Provider-hidden instructions and exact server token IDs are unavailable.
- **Knowledge** opens in 2D. The floating Colors & memory scope panel is removed;
  domain colors and optional 3D remain available.
- New voice logs receive titles from substantive conversation topics. Human
  title edits take precedence; existing saved logs are not renamed in bulk.

Close and reopen the PWA after the host update to load matching UI assets. For
the prompt inspector, send the chosen character a message first: snapshots are
kept in memory and start empty after a host restart. Voice engines and models
are unchanged by this update.

See [Settings](../settings.md), [Knowledge](../knowledge.md) and [Voice](../voice.md)
for controls, retention boundaries and usage details.
