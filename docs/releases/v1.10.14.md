# HUB 1.10.14

The assistant can show you the PC's screen whenever you are talking with it, however you ask: "again", "show me", or as part of a desktop task. It no longer depends on the word "screenshot". Work running in the background still cannot capture your screen.

Assistants are told that a screenshot saved to a file does not appear in the chat, so they use HUB's own capture, which does.
