# HUB 1.10.16

Characters can hand work to each other again: delegating to a character with a restricted tool list (such as the voice assistant) used to fail every time.

When you share your iPhone screen, HUB can draw more than boxes on it: aim lines, bank-shot paths with bends, and target circles, so it can show you a shot in a pool game or a route on a map. Includes 1.10.15.
