# HUB 1.10.0

This host update supplies the authenticated conversation, notification and
consented screen-sharing endpoints used by the separate iPhone companion.
Existing PWA and Telegram conversations and character, model, speech and
Knowledge settings are preserved.

The iPhone companion uses native audio for background conversations and keeps
its remote web content and generated HTML outside the native privilege boundary.
Screen capture requires an explicit user action; agents receive only the fresh
frames authorized for the current conversation. Notifications remain opt-in and
require an Apple delivery key on the host.

The iPhone build is a TestFlight development client. Real Apple signing and
App Store export have passed; physical iPhone voice, lock-screen, Bluetooth,
Siri, notification and sharing acceptance remain separate checks. This release
does not claim those device checks have passed or publish an iPhone installer.
