# HUB 1.4.0 — Soniox speech setup

Soniox streaming recognition can now be connected in Settings → HUB → Speech.
The API key stays in the host credential store. Speech synthesis and character
voices retain their existing local engine and settings.

Foreground calls stream to Soniox. Background waiting closes that connection and
uses a local wake listener; hangup also stops streaming. The PWA Mute control
only disables the microphone; Background stops the paid stream. Interim words
stay visible, completed utterances enter the same conversation, and connection
or balance errors provide a local waiting state with a way to retry.

This local candidate has protocol, settings and synthetic audio checks. Live
Soniox recognition and physical phone acceptance require the user's own key and
are not yet verified. No public binary release is claimed by these checks.

See the [voice setup guide](../voice.md#soniox-streaming-recognition).
