# HUB 1.10.5

The native iPhone app can list the files HUB wrote in a conversation and
open each one. HUB sends each file's name, size and SHA-256 checksum so the
phone can verify the download.

Voice typing in the native iPhone app uses your Soniox connection. HUB gives
the phone a key that expires after two minutes, and the phone sends the
microphone audio to Soniox itself. No voice call starts, and the stored
Soniox key stays on HUB. English and Turkish can be mixed in one sentence.

This release also includes the 1.10.4 Windows screenshot fix.
