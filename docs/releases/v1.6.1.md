# HUB 1.6.1

Model replies stream again when the live catalogue's capability checks are
enabled. The checks now preserve the native agent stream, including no-tool
Knowledge AI workers and requests to other providers.

Changing the Knowledge AI provider or model also returns older credit-waiting
jobs to the normal queue. The newly selected provider's availability, processing
mode and existing budget limits still apply. Other failed jobs remain available
for explicit retry; no validation rule or saved character permission is relaxed.

Reopening an older conversation no longer reapplies its historical credit errors
to the provider selected today. Original error records remain in chat history.

This patch preserves the 1.6 home, agenda, catalogue and original-file features.
Physical phone acceptance for the earlier voice changes remains pending; this
patch does not claim to verify microphone, speakerphone or interruption quality.
