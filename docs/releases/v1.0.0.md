# HUB v1.0.0

HUB's first product release brings the current Windows host, mobile PWA and
Telegram assistant together as the 1.0 baseline. Future releases will focus on
complete, polished user workflows, with clear verification and recovery behavior.

## Included

- A unified bottom Write/Speak area, compact chat activity and phone-sized controls.
- Characters with model, voice and tool policies; delegation and live task results.
- Paired Telegram text and an optional incoming voice-call bridge.
- An Obsidian-compatible Knowledge vault, a separate archive of original chats,
  domain-aware retrieval, generated `memory.md` and portable Skills.
- Unified Tasks for Goals and scheduled/recurring work, with editable limits and history.
- A real tool inventory, observed-control browser actions, supported media inspection
  and conversation visuals.
- Native context compaction with recoverable original history and safer cancellation.

## Install or upgrade

Download **HUB-windows-x64.exe** from this release. `SHA256SUMS` contains its expected
SHA-256 digest. Run the installer using the same Windows account as an existing
installation. Allow active tasks/calls to finish first. Existing local conversations,
vault sources, characters, provider connections and settings are retained; the
installer does not reset your data.

The installer includes the host and PWA assets. Keep the host running, then refresh
an existing PWA tab when ready. Remote microphone access needs authenticated HTTPS.
Model-provider accounts, credentials and speech-model weights are not bundled.
Follow the [setup](https://github.com/mbaykam/HUB/blob/v1.0.0/docs/setup.md),
[voice](https://github.com/mbaykam/HUB/blob/v1.0.0/docs/voice.md),
[Telegram](https://github.com/mbaykam/HUB/blob/v1.0.0/docs/telegram.md) and
[Knowledge](https://github.com/mbaykam/HUB/blob/v1.0.0/docs/knowledge.md) guides for optional capabilities.

## Scope and known boundaries

- This release provides a **Windows x64** download. macOS/Linux packaging remains
  available in source; their voice/device workflows are not certified by this release.
- The installer is currently **unsigned**. No publisher signing certificate is bundled.
- Voice quality and latency depend on selected engines, hardware and acoustics.
  The playback guard is not full acoustic echo cancellation. Fixture tests do not
  establish full-day physical phone/audio reliability.
- Website tools operate websites, rather than arbitrary Windows applications.
  Instagram and other platforms can block public acquisition; attaching the clip
  provides a supported inspection path. Sampled frames have coverage limits.
- Compaction is lossy; original conversations and cited sources remain available
  for recovery. Provider limits can still pause model-dependent work.

No macOS/Linux acceptance, unrestricted video access or untested physical voice
performance is implied by the 1.0 version number. See the
[release standard](https://github.com/mbaykam/HUB/blob/v1.0.0/RELEASING.md).
