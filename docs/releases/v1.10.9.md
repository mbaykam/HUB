# HUB 1.10.9

Assistants can use this Windows PC the way a person at the keyboard would.
hub_desktop_look shows them the screen and the open windows, and
hub_desktop_act clicks, types, presses key combinations, scrolls, drags and
switches windows. They work in a look, act, look-again loop, ask before
purchases, messages, deletions or security settings, and never type passwords.
