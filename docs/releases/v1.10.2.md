# HUB 1.10.2

Knowledge AI now has an activity entry beside Knowledge in the phone sidebar.
Its read-only log shows saved jobs, recorded start/end times, retry explanations,
committed note/domain/tag/link changes and their original sources. It does not
run a model when opened, invent missing historical timings or retry work.

The matching iPhone development client packages the actual renderer and its
static assets inside the app. A fresh Home can mount without downloading the UI
or restoring a prior screen/draft. API requests and stream connections wait for
the authenticated host compatibility check. Sign-in and incompatible hosts retain
the ordinary HTTPS web interface, and Reload from HUB offers explicit recovery.
The initial workspace-picker state also uses the compact composer. Its menu opens
the existing workspace picker while Send remains locked; normal conversation
actions replace that recovery menu after a session is available.

The iPhone web view overrides the public input accessory property to remove the
form-navigation strip, keeping WebKit's existing editor and system keyboard.
Actual simulator evidence and physical iPhone acceptance are recorded separately.
This release does not claim measured phone startup latency, better speech quality
or completed physical-device keyboard/voice acceptance.
